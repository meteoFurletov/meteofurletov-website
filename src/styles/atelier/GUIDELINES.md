# Atelier — brand rules (summary)

Short reference distilled from the original handoff's 12 guideline specimens
(`Atelier Design System-handoff.zip`, not copied into this repo — see below).

- **Tone:** "Caslon display over calm Newsreader, on warm paper. One palette,
  two energies." Quiet, editorial, restrained — like a well-made magazine.
- **Flat fields only** — no gradients, no noise/texture, no mesh backgrounds.
- **One accent per composition.** Saffron (`--color-highlight`) is reserved for
  a single highlight — don't spread it across a page.
- **Two modes, not a light/dark toggle:**
  - **Bloom** — "everyday." Light paper background, ink text. The default for
    all body content.
  - **Ember** — "accent / after hours." Dark petrol ground
    (`--color-ground-dark`), on-dark text. Reserved for hero/cover moments —
    used sparingly (this site: only the Home hero).
- **Icons:** Lucide, 1.5px stroke, round caps/joins. Line icons only — no
  filled icons, no emoji, no bitmap textures.
- **Motion:** minimal — 0.15s ease transitions, no bounce/spring easing.
- **Shadows:** restrained (`--shadow-card`, `--shadow-raised` only — avoid
  inventing heavier shadows).

Full specimen HTML (colors, type scale, spacing, data-viz order, etc.) lives
in the original handoff zip, not duplicated here — see
`Atelier Design System-handoff.zip` if you need the full detail.
