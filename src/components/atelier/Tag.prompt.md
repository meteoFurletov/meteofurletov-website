A small uppercase mono pill for categories, statuses, and metadata.

```jsx
<Tag tone="olive">olive</Tag>
<Tag tone="saffron">highlight</Tag>
<Tag tone="petrol">on dark</Tag>
```

Tones: `olive`, `saffron`, `petrol`, `terracotta`, `neutral`. Keep labels short; reserve `saffron` for the one thing that should draw the eye.
